# Phase I: Benchmark Evaluation

## Dataset
- EEG Eye State (OpenML 1471)
- 14,980 samples
- 14 EEG channels

## Results

| Model | Accuracy |
|------|----------|
| HRF v15.0 | 98.84% |
| Extra Trees | 94.49% |
| Random Forest | 93.09% |
| XGBoost | 92.99% |

## Key Insight
HRF significantly outperforms ensemble baselines.
