# Harmonic Resonance Fields (HRF)

Physics-informed machine learning framework for EEG classification using harmonic resonance modeling.

## Research Summary
HRF models classification as wave interference in a high-dimensional feature space.

## Key Achievement
- 98.84% accuracy (EEG Eye State, OpenML 1471)
- GPU-accelerated implementation (v15.0)
- Robust to temporal jitter and noise

## Versions
- v15.0 → Stable benchmark (recommended)
- v16.0 → Experimental high-variance model

## Warning
Use v15.0 for reproducible research.
